## 🧬 Biomedical Domain & Simulation Focus
*   **Physiological Modeling:** Currently building cardiovascular simulators and complex physiological sandboxes that capture real biological behaviors.
*   **Cardiovascular Architecture:** Implementation of Windkessel models, heart dynamics, Frank-Starling feedback mechanisms, and clinical scenario simulations (heart failure, bradycardia, hypertension).
*   **Organic Modeling:** Deeply exploring the 3D computational modeling of intricate organic structures.

###

## 🚀 Featured Systems & Apps

*   **[BioSys Sandbox](https://github.com/swostika0414/BioSys)** – A computational cardiovascular & physiological systems simulator built from scratch using Python, NumPy, and Matplotlib.
*   **[MATRI](https://github.com/swostika0414/MATRI-2.0)** – A maternal health monitoring system designed for early complication detection in rural Nepal, running local risk prediction models offline over SMS networks using Flutter, Dart, SQLite, and BLE.
